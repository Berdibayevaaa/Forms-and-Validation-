## Project Description

This project demonstrates how to create HTML forms, use HTML5 validation, style forms with Bootstrap, and validate user input using JavaScript.

## Task 0 — Basic HTML Form

**Objective:** Create a simple contact form using HTML.

The form contains:
- Name
- Email
- Message
- Submit button

Each input has a corresponding label. This task demonstrates the basic structure of an HTML form.

## Task 1 — HTML5 Validation

**Objective:** Add built-in browser validation to the contact form.

The form uses the following attributes:
- `required` — makes a field mandatory.
- `type="email"` — checks the email format.
- `minlength` — sets the minimum number of characters.
- `maxlength` — sets the maximum number of characters.

The browser displays validation messages when the user submits invalid data.

## Task 2 — Bootstrap Form Styling

**Objective:** Style the contact form using Bootstrap.

The form uses:
- `container` to organize and center the content.
- `card` to create a white form panel.
- `row` and `col-md-6` to arrange fields responsively.
- `form-control` to style inputs and textareas.
- `form-label` to style labels.
- `btn btn-primary` to style the Submit button.

Placeholders and helper text make the form easier to use.

## Task 3 — Bootstrap Validation Styles

**Objective:** Display validation feedback using Bootstrap and JavaScript.

The form uses:
- `checkValidity()` to check whether an input satisfies its HTML validation rules.
- `is-valid` to show successful validation.
- `is-invalid` to show invalid input.
- `valid-feedback` and `invalid-feedback` to display messages.
- `preventDefault()` to prevent the page from reloading when the form is submitted.

## Task 4 — Registration Form

**Objective:** Create a responsive registration form with validation.

The form contains:
- First Name and Last Name
- Email
- Password and Confirm Password
- Gender radio buttons
- Hobbies checkboxes
- Country dropdown
- Register and Reset buttons

HTML5 attributes validate required fields and password length. JavaScript checks whether the passwords match and displays validation feedback. Bootstrap Grid makes the layout responsive.
